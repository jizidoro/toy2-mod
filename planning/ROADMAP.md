# Roadmap

The forward map: what the project is for, what is live, which objectives are shipped, ready,
blocked or ruled out, and what comes next in order. One row per objective; the detail lives in
the linked plan. Update the row when the state changes (`/update-map`), not the plan.

Legend: ✅ shipped · 🟡 partly live · 🔜 ready (everything it needs is in hand) · 🔎 needs a dig
first · ⬜ not started · ⛔ ruled out.

## Vision
Toy Story 2: Buzz Lightyear to the Rescue (PC, 1999), from the owner's ISO, running on this PC
(RTX 5090; `DISPLAY1` 3840×2160@240, `DISPLAY2` primary 5120×2160@165). **Goal set by the owner
(jhonatan), 2026-09-28: "run it in 120fps and 4k, with a support for mods"**, plus borderless
fullscreen and, if possible, an HD texture pack. Earlier direction the same day: "run the toy story 2
on our side … my original game don't run in 4k", then "the best version ever possible". The
community repack (Dec 2025) on the Desktop is a reference to improve our own build, not a
replacement ("maybe it can help us a little to improve ours").

## Risks
- Full-screen runs take DISPLAY1 and play sound; ask before runs when the owner may be on a call there.
- Third-party binaries (dgVoodoo, AndetSTK's ASI, Xidi, DSOAL) have no source in hand or unknown licences; keep each one swappable and its hash recorded.
- True 120 Hz simulation may be infeasible: every frame-step assumption in the game would need finding and fixing.
